## Solar System (OpenGL / GLSL, C++) - IGR200

Interactive solar system renderer built with **C++** and **OpenGL**, with GPU-side rendering written in **GLSL**.

This project was developed for a computer graphics course focused on:
- the OpenGL rendering pipeline and real-time interactive applications
- core graphics concepts (transformations, camera, lighting)
- GPU programming through shader development (GLSL)
- clean C++ / object-oriented structure for graphics applications
